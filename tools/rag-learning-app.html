RAG Studio

What is RAG?

Retrieval-Augmented Generation — the technique of grounding an LLM's answers in your own documents. Instead of relying on training data alone, the model retrieves relevant context at query time and generates grounded, accurate responses.

The core problem RAG solves: LLMs hallucinate when asked about facts they don't know. RAG gives the model evidence to reason over, dramatically reducing hallucination on domain-specific content.
FOUNDATION

🔢 Embeddings

Dense vector representations of text that capture semantic meaning. Similar concepts have vectors close together in high-dimensional space.

An embedding model (like text-embedding-3-small) converts text → a list of floats, e.g. 1536 numbers. The geometric distance between two vectors reflects semantic similarity.

# "apple" and "fruit" → nearby vectors # "apple" and "kubernetes" → distant vectors vec = embed("How does Kafka handle backpressure?") # → [0.021, -0.834, 0.112, ... ] (1536 dims)
STORAGE

🗄️ Vector Store

A database optimized for storing and querying embeddings. Finds the top-k most similar vectors to a query using approximate nearest neighbour search.

Options by scale: ChromaDB (local, great for dev), FAISS (in-memory, Meta), Pinecone/Weaviate/Qdrant (cloud, production). For your Substack project, ChromaDB is perfect.

INGESTION

✂️ Chunking

Splitting documents into smaller pieces before embedding. The chunking strategy dramatically affects retrieval quality.

Chunk too large → retrieved context includes noise. Chunk too small → loses context. Common strategies:

# Fixed-size (simple, works ok) RecursiveCharacterTextSplitter(chunk_size=512, overlap=50) # Semantic (better quality) SemanticChunker(embedding_model) # Sentence-window (best for Q&A) # Store sentence, retrieve ±N sentences for context
RETRIEVAL

🔍 Hybrid Search

Combining dense (semantic) + sparse (keyword/BM25) retrieval. Better than either alone — catches both semantic and exact matches.

Dense search misses exact keyword matches. BM25 misses paraphrases. Hybrid combines both and uses Reciprocal Rank Fusion to merge result lists.

# Dense: semantic similarity dense_results = vector_search(query_vec, k=10) # Sparse: exact keyword match sparse_results = bm25_search(query_text, k=10) # Fuse with RRF final = reciprocal_rank_fusion([dense_results, sparse_results])
QUALITY

↕️ Reranking

A cross-encoder model that rescores the top-k retrieved chunks for precise relevance to the query. Slower but much more accurate than vector similarity alone.

Bi-encoders (used in retrieval) are fast but imprecise. Cross-encoders see query + passage together and score much more accurately. Use Cohere Rerank or a local cross-encoder.

# Retrieve 20, rerank to top 5 candidates = vector_search(query, k=20) reranked = cohere.rerank( query=query, documents=candidates, top_n=5 )
EVALUATION

📊 RAGAS Metrics

The standard eval framework for RAG systems. Measures faithfulness, answer relevance, context precision, and context recall.

MetricMeasures

Context PrecisionIs retrieved context relevant (no noise)?
Context RecallWas all needed info retrieved?

📄 Load Documents

Parse raw files into plain text. Different loaders for different formats — PDF (PyMuPDF), Markdown, HTML, DOCX. For your Substack project, you'd export posts as Markdown and load them here.

from langchain.document_loaders import DirectoryLoader, TextLoader loader = DirectoryLoader("./posts/", glob="**/*.md", loader_cls=TextLoader) docs = loader.load() # → list of Document(page_content="...", metadata={"source": "kafka-post.md"})

✂️ Chunking Strategy

Split documents into overlapping chunks. Overlap ensures context isn't lost at chunk boundaries. 512 tokens with 50-token overlap is a solid starting point.

from langchain.text_splitter import RecursiveCharacterTextSplitter splitter = RecursiveCharacterTextSplitter( chunk_size=512, chunk_overlap=50, separators=["\n\n", "\n", ". ", " "] # try paragraph first ) chunks = splitter.split_documents(docs) # → ~3x more chunks than documents

🔢 Embed Chunks

Convert each chunk to a dense vector. OpenAI's text-embedding-3-small is cheap and accurate (1536 dims). Cost: ~$0.02 per 1M tokens — for 100 Substack posts, essentially free.

from langchain_openai import OpenAIEmbeddings embeddings = OpenAIEmbeddings(model="text-embedding-3-small") vecs = embeddings.embed_documents([c.page_content for c in chunks]) # → [[0.021, -0.834, ...], ...] one vec per chunk

🗄️ Store in Vector DB

Persist vectors + original text + metadata. ChromaDB stores everything locally in a folder — perfect for dev. Can query in milliseconds with cosine similarity.

import chromadb from langchain_chroma import Chroma vectorstore = Chroma.from_documents( documents=chunks, embedding=embeddings, persist_directory="./chroma_db" ) # Persisted! Reload next time with: vectorstore = Chroma(persist_directory="./chroma_db", embedding_function=embeddings)

❓ Embed the Query

The user's question is embedded using the same model used during ingestion. This puts the query in the same vector space as the chunks.

query = "How does Kafka handle consumer group rebalancing?" query_vec = embeddings.embed_query(query) # → [0.034, -0.291, ...] (1536 dims) # Now we can find chunks near this vector

🔍 Retrieve Top-K Chunks

Find the k most similar chunks via cosine similarity. Start with k=5 for generation context. Retrieve k=20 if you plan to rerank.

# Basic similarity search results = vectorstore.similarity_search(query, k=5) # With scores (0→1, higher=more similar) results = vectorstore.similarity_search_with_score(query, k=5) # → [(Document(page_content="...", metadata={}), 0.87), ...] # Metadata filtering (e.g. only search one category) results = vectorstore.similarity_search( query, k=5, filter={"category": "distributed-systems"} )

↕️ Rerank for Precision

Optional but high-value. A cross-encoder sees (query, passage) together and produces a precise relevance score. Cohere Rerank is the easiest production option.

import cohere co = cohere.Client(api_key) reranked = co.rerank( query=query, documents=[r.page_content for r in results], top_n=3, model="rerank-english-v3.0" ) # Gets you the 3 most relevant from your top-20

🤖 Generate with Context

Stuff retrieved chunks into the prompt as context. The LLM is instructed to answer using only the provided context — grounding the response and reducing hallucination.

context = "\n\n".join([r.page_content for r in top_chunks]) prompt = f"""Answer the question using ONLY the context below. If the answer isn't in the context, say "I don't know." CONTEXT: {context} QUESTION: {query} ANSWER:""" response = claude.complete(prompt)

📊 Evaluate with RAGAS

Build a golden test set of 50-100 questions with known good answers. Run RAGAS after every pipeline change. Target: faithfulness >0.85, context precision >0.75.

from ragas import evaluate from ragas.metrics import faithfulness, answer_relevancy, context_precision dataset = Dataset.from_dict({ "question": ["How does Kafka handle rebalancing?"], "answer": [generated_answer], "contexts": [retrieved_chunks], "ground_truth": [known_good_answer] }) result = evaluate(dataset, metrics=[faithfulness, answer_relevancy, context_precision]) # {'faithfulness': 0.89, 'answer_relevancy': 0.91, 'context_precision': 0.78}

Build it Yourself

Full Python code for a production-ready RAG system. Uses LangChain + ChromaDB + Claude API. Copy, run, extend.

Install dependencies and set up your environment. Uses Claude API for generation, OpenAI for embeddings (cheapest option), ChromaDB for local vector storage.

# Install pip install langchain langchain-openai langchain-anthropic langchain-chroma chromadb ragas # .env file ANTHROPIC_API_KEY=sk-ant-... OPENAI_API_KEY=sk-... # for embeddings only # Project structure rag-project/ ├── ingest.py # load + chunk + embed + store ├── retrieve.py # search + rerank ├── generate.py # llm call with context ├── app.py # CLI / FastAPI ├── eval.py # RAGAS evaluation ├── documents/ # your raw files └── chroma_db/ # auto-created by ChromaDB
# ingest.py import os from pathlib import Path from langchain.document_loaders import DirectoryLoader, TextLoader from langchain.text_splitter import RecursiveCharacterTextSplitter from langchain_openai import OpenAIEmbeddings from langchain_chroma import Chroma def ingest_documents(docs_dir: str = "./documents", db_dir: str = "./chroma_db"): # 1. Load loader = DirectoryLoader(docs_dir, glob="**/*.md", loader_cls=TextLoader) docs = loader.load() print(f"Loaded {len(docs)} documents") # 2. Chunk — recursive splits on paragraph → sentence → word splitter = RecursiveCharacterTextSplitter( chunk_size=512, chunk_overlap=50, separators=["\n\n", "\n", ". ", " ", ""] ) chunks = splitter.split_documents(docs) print(f"Created {len(chunks)} chunks") # 3. Embed + 4. Store embeddings = OpenAIEmbeddings(model="text-embedding-3-small") vectorstore = Chroma.from_documents( documents=chunks, embedding=embeddings, persist_directory=db_dir, collection_metadata={"hnsw:space": "cosine"} ) print(f"Stored in ChromaDB at {db_dir}") return vectorstore if __name__ == "__main__": ingest_documents()
# retrieve.py from langchain_openai import OpenAIEmbeddings from langchain_chroma import Chroma from anthropic import Anthropic client = Anthropic() def load_vectorstore(db_dir: str = "./chroma_db"): embeddings = OpenAIEmbeddings(model="text-embedding-3-small") return Chroma(persist_directory=db_dir, embedding_function=embeddings) def retrieve_and_generate(query: str, vectorstore, k: int = 5) -> dict: # Retrieve top-k results = vectorstore.similarity_search_with_score(query, k=k) # Filter low-relevance chunks (cosine similarity < 0.3) relevant = [(doc, score) for doc, score in results if score > 0.3] if not relevant: return {"answer": "No relevant context found in the knowledge base.", "chunks": []} # Build context context_parts = [] for i, (doc, score) in enumerate(relevant): source = doc.metadata.get("source", "unknown") context_parts.append(f"[{i+1}] (from {source}, relevance={score:.2f})\n{doc.page_content}") context = "\n\n".join(context_parts) # Generate with Claude response = client.messages.create( model="claude-sonnet-4-20250514", max_tokens=1024, system="""You are a helpful assistant that answers questions based on provided context. Rules: - Answer ONLY from the context provided - If the answer isn't in the context, say "I don't find this in the provided documents" - Always be specific and cite which source section you're drawing from - Be concise but complete""", messages=[{ "role": "user", "content": f"CONTEXT:\n{context}\n\nQUESTION: {query}" }] ) return { "answer": response.content[0].text, "chunks": [(doc.page_content, score, doc.metadata) for doc, score in relevant] }
# app.py — FastAPI REST API from fastapi import FastAPI, HTTPException from pydantic import BaseModel from retrieve import load_vectorstore, retrieve_and_generate from ingest import ingest_documents import time app = FastAPI(title="RAG API") vectorstore = None class QueryRequest(BaseModel): query: str k: int = 5 @app.post("/ingest") async def trigger_ingest(): global vectorstore vectorstore = ingest_documents() return {"status": "ok", "message": "Ingestion complete"} @app.post("/query") async def query(req: QueryRequest): if not vectorstore: raise HTTPException(400, detail="Run /ingest first") start = time.time() result = retrieve_and_generate(req.query, vectorstore, req.k) latency = time.time() - start return { "answer": result["answer"], "sources": [ {"text": t[:200], "score": round(s, 3), "source": m.get("source")} for t, s, m in result["chunks"] ], "latency_ms": round(latency * 1000) } # Run: uvicorn app:app --reload # Test: curl -X POST http://localhost:8000/query \ # -H "Content-Type: application/json" \ # -d '{"query": "How does X work?", "k": 5}'
# eval.py — RAGAS evaluation harness from datasets import Dataset from ragas import evaluate from ragas.metrics import ( faithfulness, answer_relevancy, context_precision, context_recall ) from retrieve import load_vectorstore, retrieve_and_generate # Your golden test set — build this from your domain GOLDEN_QA = [ { "question": "How does Kafka consumer group rebalancing work?", "ground_truth": "When a consumer joins or leaves a group..." }, # Add 50+ pairs for meaningful eval ] def run_eval(): vectorstore = load_vectorstore() questions, answers, contexts, ground_truths = [], [], [], [] for qa in GOLDEN_QA: result = retrieve_and_generate(qa["question"], vectorstore) questions.append(qa["question"]) answers.append(result["answer"]) contexts.append([c[0] for c in result["chunks"]]) ground_truths.append(qa["ground_truth"]) dataset = Dataset.from_dict({ "question": questions, "answer": answers, "contexts": contexts, "ground_truth": ground_truths }) results = evaluate( dataset, metrics=[faithfulness, answer_relevancy, context_precision, context_recall] ) print("\n=== RAGAS SCORES ===") print(f"Faithfulness: {results['faithfulness']:.3f} (target: >0.85)") print(f"Answer Relevancy: {results['answer_relevancy']:.3f} (target: >0.80)") print(f"Context Precision: {results['context_precision']:.3f} (target: >0.75)") print(f"Context Recall: {results['context_recall']:.3f} (target: >0.70)") return results if __name__ == "__main__": run_eval()
